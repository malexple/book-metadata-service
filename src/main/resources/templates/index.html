Быстрый старт

Публичный поиск не требует ключа и ограничен 60 запросами в минуту с одного IP:

curl "https://ваш-домен/api/v1/search/isbn/9785171234567"
            curl "https://ваш-домен/api/v1/search/title?q=Мастер+и+Маргарита"
            curl "https://ваш-домен/api/v1/search?q=9785171234567"

Хотите создавать/обогащать карточки программно — напишите нам за партнёрским ключом (доступ по scope PARTNER_WRITE). Полная документация — в Swagger UI.
